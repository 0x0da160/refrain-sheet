# Unused-code baseline (Knip)

**Status: current-state report.** It lists every finding a fresh `npx knip`
run reports against `knip.jsonc`, how each is classified, and why it stays.
CI enforces it: `npm run check:knip` (`scripts/check/knip.mjs`) fails on any
finding that is not on that script's explicit `DEFERRED` list, and on a
`DEFERRED` entry that is no longer reported. Refresh this file with the
`cleanup-audit` skill; act on an S0 finding with the `safe-delete` skill.

Findings are classified S0–S3: S0 mechanically safe to delete → S1
cross-file-unused only (unexport, keep the code) → S2 needs human judgment →
S3 external contract (RSF format, `wasm/` codecs, persisted data, public
API). Only S0 is ever auto-actionable. `tsconfig.json`'s
`noUnusedLocals`/`noUnusedParameters` and ESLint's `no-unused-vars` already
catch unused locals, parameters, and imports; Knip adds unused **exports**,
**files**, and **dependencies** across file boundaries.

## Config notes (why each entry/ignore in `knip.jsonc` exists)

- `site/main.js`, `site/consent.js` are explicit entries:
  `site/template.html` (and the other page templates) load them with plain `<script src="…">`
  tags, which Knip cannot follow. `site/i18n.js` needs no entry — it
  is a real `import` of `scripts/build/landing.mjs`.
- `src/generated/**` is ignored: generated by `npm run build:wasm` /
  `build:sqljs`, never hand-edited (`.gitattributes: linguist-generated`).
- `tailwindcss` is in `ignoreDependencies`: it is used only through CSS
  `@import 'tailwindcss/theme.css'` / `'tailwindcss/utilities.css'` in
  `src/styles/tokens.css:26-27`, and Knip's `project` globs do not include
  `*.css`.
- `design-system/`, `dist/`, `dist-hosted/`, `landing/` match no `project`
  glob, so Knip never reads them.

## Resolved (kept for the lessons; details in each PR)

- **S3 `DEFAULT_SHEET_NAME`** (`src/core/rsf-document.ts`) — used only inside
  its own file, so the `export` was removed and the value (`'Sheet1'`) is
  unchanged. No byte of the RSF format depends on the keyword; the frozen
  `.rsf` fixture corpus and `test:rust` still pass.
- **S2 `MAX_JOIN_ITEMS`** (`src/core/formula-value.ts`) — removed. No `REPT`
  function exists, and `CONCAT` / `TEXTJOIN` are already bounded by
  `MAX_TEXT_LENGTH` (output) and `MAX_RANGE_CELLS` (input), so the constant
  guarded nothing. This also clears Knip's duplicate-export report.

- **Unlisted `@eslint/js`** — declared as a pinned devDependency; **unlisted
  `wasm-pack`** — moved to `ignoreBinaries` (`308e3a7`); no longer needed
  once `build:wasm` ran it from `scripts/build/wasm.mjs`.
- **Formula-engine export surface** (`2165c33`) — 14 redundant barrel
  re-exports trimmed from `formula.ts`, internal-only bindings unexported,
  dead helpers removed (`isVolatileFunction`, `isSingleCell`, `isError`,
  `gridError`, `finiteNumber`).
- **Dead helpers** (`6ccd230`) — `rangeSize`, `rowHiddenByFilter`,
  `ColorKey`, `openPopover`, and the never-wired `spill.ts` cluster
  (`anchorOfDerived`/`derivedValue`/`isDerivedCell`/`isBlockedAnchor`;
  `rsf-document.ts` implements those lookups inline).
- **Export surface** (`cebb118`) — 30 values and 12 types used only inside
  their own file were unexported, not deleted.
- **Test-reset hooks** (`fc6572c`) — `resetAuthStateForTests`,
  `resetPickerStateForTests`, `resetSqlEngineForTests`, never called.

Two lessons from those passes still apply: (1) Knip's "unused export" means
_cross-file_ unused — most findings were used inside their own file, so the
fix was removing `export`, not the code; (2) an occurrence count is only a
heuristic — `finiteNumber`'s and `openPopover`'s extra "uses" were
doc-comment mentions (`{@link …}`), which `npm run lint` caught.
