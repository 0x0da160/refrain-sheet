# Changelog

## 1.0.0 — 2026-09-22

最初のリリース。ブランドガイドライン v2.0 を出典に、Webアプリケーション向けの
デザインシステムとして構成しました。以降はこの版を唯一の参照とします。

### 追加
- **トークン** — 色（Oklab設計・3テーマ）、文字、余白、角丸、コントロール、密度、
  モーション、階層、ブレークポイント。`css/tokens.css`
- **コンポーネント** — コントロール共通クラス、ボタン4種×6状態、フォーム、
  意味別チップ、データシート、アプリシェル、オーバーレイ、通知、スケルトン。
- **3テーマ** — light / dark / hybrid（シェルは暗くシートは紙）。
  `prefers-color-scheme` に追随し、`data-theme` で上書き。
- **3密度** — compact / comfortable / spacious。粗いポインタでは44px下限を強制。
- **アイコン・ロゴタイプ** — iOS / Android / favicon / PWA と、
  アウトライン化済みロゴタイプ4種。

### ブランドガイドラインからの変更（すべて環境制約が理由）
- **中間ウェイトを廃止。** BIZ UD系はウェイトが400と700しかなく、500/600は
  レンダリング時に落ちる。階層はサイズ・色・余白で作る。
- **文字サイズの下限を14pxに。** 以前の11px/12pxトークンを削除。
  本文・UIラベル・ボタン・セルはすべて16px。
- **大文字トラッキングを0.08em→0.04emに。** 0.08emは過剰。
- **単位を px から rem へ。** 文字・文字まわりの余白・コントロール高。
  境界線と影は px のまま、メディアクエリは em。
- **ロゴタイプの "Sheet" は Medium 500** だが、これはアウトライン化された
  図形であってUIテキストではない。ライブテキストで再現しないこと。

### 検証
- コントラスト監査 78/78 合格（3テーマ全組み合わせ）
- リテラル色 0件（`tools/lint_tokens.py`）
- フォントの実在ウェイト・OpenType機能を Windows 11 の実ファイルで確認
