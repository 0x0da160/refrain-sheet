Scope

この規定の適用範囲

対象

画面上のプロダクトUI（デスクトップアプリ・Web）、アプリアイコン、Webサイト、 製品内のドキュメント。色はsRGB前提、言語は日本語を第一に、英数字が混在する前提で設計しています。

対象外

印刷物・特色・CMYK出力。紙で成立する淡い色や罫線は画面では別の値になります。 印刷が必要になった時点で、この規定に印刷向けの節を足してください。

v1.0 との関係

アイコンの幾何とブランド4色は v1.0 から変更していません。v1.0 のCSSにあった --line: #D8DED7 と --muted: #5B6468 は、スケールを滑らかにするため --paper-200 / --ink-400 に寄せています（いずれも明度差1%未満）。

規定は証拠であって法ではありません。画面で再現できる制約（コントラスト・可読性・ ライセンス・描画）が規定と衝突した場合は、制約が優先です。その差分は「逸脱」ではなく 「規定の不足」として、この文書に戻してください。

Shape Language

形の言語

角の丸みは、文章を読む前にユーザーへ届く最初のメッセージです。Refrain Sheet の形は アイコンがすでに答えを持っています──外側はやわらかく、データは直角。

アイコンが決めている3つのこと

  • 外周は連続角丸（22.37%） — 親しみやすく、道具として落ち着いた印象。 シェル（ボタン・カード・モーダル）はこの系統を受け継ぎ、6〜14pxの穏やかな丸みにする。
  • 内側の3つのセルは丸く、右下だけ直角 — データそのものは角を持つ。 グリッドのセル・行・列ヘッダは --radius-cell: 0。ここを丸めない。
  • 面で読ませる — 線や影ではなく、色面と余白で構造を示す。 境界線は最小限、影は浮かせる必要があるものだけ。

大きい面ほど同じ半径は「角ばって」見えます。モーダル14px＞カード10px＞ボタン6px という差は、見た目の丸みを揃えるための調整です。逆にウェル（沈んだ背景領域）は 4px に留め、中身より容器が目立たないようにします。

アプリアイコンの外周だけは連続角丸（squircle）です。UIの border-radius は通常の円弧で成立するよう設計しており、対応ブラウザでは corner-shape: squircle により自動的に連続角丸へ昇格します（未対応でも破綻しません）。

Logotype

ロゴタイプ

構成

Inter（opsz 32）の Bold 700 ＋ Medium 500。全体トラッキング −0.0223em に 光学的な字詰め補正を加え、アウトライン化して固定しています。ライブテキストで 組み直さないでください。

アイソレーション / 最小サイズ

四方にアイコン辺長の1/4以上の余白。横組みロックアップは高さ24px（印刷8mm）まで。 それ以下ではアイコン単体を使います。

背景別

淡色 → 標準形。Ink など濃色 → reverse。Dominant green の上では アイコンの地が背景に溶けるため、ロックアップではなく refrain-sheet-wordmark-mono.svg を Paper 色で使います。

詳細な寸法・字詰めテーブル・禁止事項は logo/SPEC.md を参照してください。

Colour System

カラーシステム

色は Oklab（極座標表記の OKLCH）で設計し、納品値は互換性のため sRGB 16進で書き出します。 Oklab を使う理由は、明度（L）がそのまま知覚上の明るさに対応するため、 同じLなら同じ重さに見えるというスケール設計ができるからです。

紙とインク、2つの中間色

中間色を1本のグレースケールにまとめず、Paper（暖色・H106.6）と Ink（寒色・H255.7）の二極に分けています。製品が扱うものが 「紙とその上の記録」だからで、ライトテーマでは紙が面・インクが文字、 ダークテーマではその関係が反転します。

緑の色相パスはブランドが決めている

Mist(H142.5) → Leaf(H147.5) → Preserve(H152.3)。明るいほど黄側に寄るこの軌跡は 既存の4色がすでに持っていたもので、スケール全体を H = 152.3 − 0.2456 × (L − 52.5) として延長しました。 ブランド3色はスケール上に値そのままで乗っています。

彩度は sRGB へ収める

各ステップは目標彩度で生成し、sRGB外に出る場合はL と H を保ったまま 彩度だけを二分探索で落としています。色相が転ばないので、 暗いステップでも「同じ緑」に見えます。

Themes

3つのテーマ

トークンはシェル（chrome：アプリの外枠）と キャンバス（canvas：データのシート）の2系統に分かれています。 テーマはこの2つの極性の組み合わせにすぎません。

テーマシェルシート想定
light紙側紙側既定。明るい環境、印刷に近い見え方でデータを確認する。
darkインク側インク側暗所での長時間作業。画面全体の発光量を落とす。
hybridインク側紙側暗所でもデータは紙として読みたい場合。 周辺光を抑えつつ、シートの見えを印刷・共有時と一致させる。

プレビュー

同じマークアップ・同じトークンで、3テーマを並べたものです。

hybrid ではシェルだけが暗くなり、シートは紙のまま保たれます。 セルの角は全テーマで直角、シェルの部品は丸められている点にも注目してください。

Typography

タイポグラフィ

Inter — UI とブランド

ヒューマニスト寄りのニュートラルなサンセリフ。暖かさと実務的な読みやすさが、 やわらかい角丸のシェルと矛盾しません。日本語は "Hiragino Sans", "Yu Gothic UI" にフォールバックします。

Refrain Sheet — 書式を保持する

等幅 — データの役割だけ

セル、数値、パス、差分、ログ。本文には使いません。 書体を3つに増やさないため、等幅はシステムフォントスタックで賄います。

0 O 1 l I 8 B 1,234,567

tabular-nums ＋ slashed-zero を常時有効化。 桁が揃い、0 と O を取り違えません。

Iconography

アイコノグラフィ

仕様

  • ライブラリは Lucide 一本（MIT）。混在させない。
  • 24pxグリッド、ストローク 1.5px、端・接合は round。
  • 表示サイズ 16 / 20 / 24px。ストローク幅はサイズによらず 1.5px を保つ。
  • 塗り（filled）はステータスドットなど、小さく確実に読ませたい場合だけ。
  • 色は currentColor。テーマ切替に自動で追従させる。

使いどころ

アイコンは語を読み飛ばすためにあります。ナビゲーション、状態、行の種別など 走査が得になる場所にだけ置き、ラベルごとに飾りで付けません。

設定＝歯車、検索＝虫眼鏡、削除＝ごみ箱、通知＝ベル。解決済みの概念に 独自の絵を発明しないこと。判読のコストだけが増えます。

1.5px という選択は、ブランドの「精密さ」と「やわらかさ」の中間です。 2pxでは道具として強すぎ、1pxでは高精細でない画面で消えます。 線の端を round にすることで、外周の連続角丸と同じ調子が保たれます。

App Icon

アプリアイコン

マスターは 1024px の正方形・角丸なし。OS が最終マスクを適用します。 プラットフォームごとの差分はデザインの変更ではなくマスク幾何への対応です。

マスター 1024 / iOS

角丸なし・透過なし。ブロックは 58.6%。

Web / favicon

連続角丸 22.37%（スムージング 0.6）。

Android モノクロ

色が使えないため、セルは抜きで示す。OSが再着色。

Implementation

実装

brand/tokens.css を読み込み、data-theme を切り替えるだけです。 OS設定に追随させる場合は属性を付けなければ prefers-color-scheme が効きます。

<link rel="stylesheet" href="/brand/tokens.css">
<link rel="icon" href="/icons/favicon.svg">
<link rel="apple-touch-icon" href="/icons/apple-touch-icon-180.png">
<link rel="manifest" href="/icons/site.webmanifest">

<html data-theme="hybrid">   <!-- light | dark | hybrid、未指定ならOS設定 -->

.toolbar {
  background: var(--chrome-surface);
  border-bottom: 1px solid var(--chrome-border);
  border-radius: var(--radius-lg) var(--radius-lg) 0 0;
}
.grid td {
  background: var(--canvas-bg);
  border: 1px solid var(--canvas-grid);
  border-radius: var(--radius-cell);   /* データは直角 */
}
.grid td[data-state="modified"] {
  background: var(--state-modified);
  color: var(--state-modified-text);
}

色は tools/palette.py が単一の出典です。 tokens.css・この文書・コントラスト監査表はすべてそこから生成されるため、 値を直接書き換えると次のビルドで戻ります。変更は palette.py に入れてください。
