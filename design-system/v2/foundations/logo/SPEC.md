アイコン部の幾何・配色は `guidelines/refrain-sheet-brand-guidelines.html` の 1024px マスターから厳密にスケールしている。

### 2.1 ウェイトのバランス

「Sheet」は Dominant green (#147F43) で組まれるため、**ウェイト差と明度コントラスト差が掛け算**で効く。
インク被覆率 × 背景との Oklab 明度差で測った各案の光学的な量（Refrain 700 = 100%）:

| Sheet のウェイト | 被覆率比 | 淡色背景での量 | 濃色背景での量 |
|---|---:|---:|---:|
| 400（draft） | 0.69 | 40.7% | 50.4% |
| 450 | 0.74 | 43.6% | 54.1% |
| **500（採用）** | **0.80** | **46.7%** | **58.0%** |
| 550 | 0.85 | 49.6% | 61.5% |

400 では、色が差の約 6 割・ウェイトが約 3 割を担い、2 つの強い信号が重なって「Sheet」が沈む。
500（Medium）にすると緑の明度ハンデを部分的に補え、Bold / Medium という標準的で読み取りやすい
階層になる。550 以上は 700 との差が曖昧になり、意図的な対比に見えなくなる。
小サイズ（ロックアップ高 24〜30px）で緑の縦線が痩せないこと、`wordmark-mono.svg` では
ウェイト差だけが唯一の差異になることも 500 を選ぶ理由。

## 3. 文字詰めテーブル（1/1000 em 単位）

「光学補正」は、各ペアの白場を x-height の 15% で深さクランプして測った平均値を、語ごとに均一化した差分。

| 語 | ペア | フォント標準カーニング | 光学補正 | 合計 |
|---|---|---:|---:|---:|
| Refrain | R–e | −24.9 | +0.3 | **−24.6** |
| Refrain | e–f | 0 | −12.4 | **−12.4** |
| Refrain | f–r | 0 | −8.2 | **−8.2** |
| Refrain | r–a | −7.3 | −12.1 | **−19.5** |
| Refrain | a–i | 0 | +11.8 | **+11.8** |
| Refrain | i–n | 0 | +20.7 | **+20.7** |
| Sheet | S–h | 0 | −0.7 | **−0.7** |
| Sheet | h–e | 0 | +4.5 | **+4.5** |
| Sheet | e–e | 0 | +1.0 | **+1.0** |
| Sheet | e–t | 0 | −4.8 | **−4.8** |

補正後の光学的白場は Refrain = 207.8 units、Sheet = 241.0 units（2048 upm）で、ばらつきは 0.00%。
これは各ウェイトにおける Inter 自身の `n|n` ステム間アキ（209.0 / 237.3）とほぼ一致する。
つまり全ペアが、その書体固有の「基準となる縦線どうしの間隔」に揃っている。

`i` まわりが開いているのは誤りではない。Inter は `i` のサイドベアリング（82.6）を `n`（104.4）より
詰めており、テキストサイズでは正しいがディスプレイサイズでは "ain" が詰まって見える。
+21/1000 em は、その差を基準値に戻す補正。

## 4. ロックアップの幾何（マスター 120px 基準）

```
アイコン           120 × 120
角丸               半径 26.844（= 22.37%）、連続角丸（スムージング 0.6）
アイコン→文字      30（= アイコン辺長 S/4）※ "R" のインク左端までの実距離
キャップハイト      54（= 0.45 S）→ フォントサイズ 74.2228
ベースライン        y = 87 / キャップ上端 y = 33 → キャップ帯の中心 60 = アイコンの垂直中心
総幅               573.37
```

**角丸は単純な円弧ではなく連続角丸（squircle）**。円弧の角は直線部との接続点で曲率が不連続になり、
角の始まりが視認できるが、連続角丸は曲率が滑らかにつながる（G2）。iOS / iPadOS / macOS が
アプリアイコンに適用するマスクと同種の形状なので、OS 上のアプリアイコンとロックアップの見えが揃う。
半径パラメータ 22.37% は Apple のアイコングリッドの等価値。

内側のセルブロックの丸み（半径 13.28%）はマスターどおりの円弧のまま。OS のマスク（連続角丸）と
円弧で描かれた内部アートワークという組み合わせは、実機のアプリアイコンとまったく同じ関係になる。

垂直方向はキャップ帯（ベースライン〜キャップハイト）の中心で合わせている。`S` の
オーバーシュート（+24 units）と丸字のベースライン下オーバーシュートはフォント側の
光学補正なので、そのまま活かす。

## 5. 運用

- **アイソレーション**：ロゴの上下左右に、アイコン辺長の 1/4（マスターで 30）以上の余白。
- **最小サイズ**：横組みロックアップは高さ 24px（印刷 8mm）まで。それ以下はアイコン単体を使う。
- **背景**：Paper / 白 → 主要形。Ink など濃色 → reverse。Dominant green (#147F43) の上では
  アイコンの地が背景に溶けるため、**ロックアップは使わず** `wordmark-mono.svg` を Paper 色で置く。
- **アプリアイコン**：ガイドラインの 1024px 正方形マスター（角丸なし）をそのまま使う。
  ロックアップの角丸は Web 用派生のためのもので、App Icon アセットには適用しない。
- **禁止**：ライブテキストでの組み直し（フォント環境で字詰めが崩れる）、字間・語間・
  ウェイトの変更、縦横比を変える拡大縮小、ブランドパレット外の着色、影・グラデーション・
  境界線の追加、アイコンと文字の距離の変更。

