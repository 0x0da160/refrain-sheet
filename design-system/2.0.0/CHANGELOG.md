# Changelog

## 2.0.0 — 2026-09-26

v1.0.0 を再評価し、表計算の密度に合わせて作り直しました。あわせて、ブランド（LP など）と
アプリ UI の規定を分け、両方が使う部分を共通基盤にまとめました。
判断の根拠は `docs/decisions.md`、調査は `docs/research.md`、
移行とアプリ・LP への適用計画は `docs/migration.md` にあります。

### 構成
- **3 層に分割** — `foundations/`（共通基盤：色・書体・余白・形・線・動き・アイコン・ロゴ）、
  `brand/`（ブランドガイドライン v3.0：LP・ドキュメント・ストア掲載）、
  `app/`（アプリ UI のデザインシステム）。層は基盤に足すだけで、上書きしない。
- **ブランドガイドライン v3.0** — v2.0 の文字規定（Inter・500/600・11px）を、実際に表示される
  OS 標準の書体と 400/700・最小 12px に合わせて書き直した。ロゴとアプリアイコンの規定は維持。

### 破壊的変更
- **トークン名** — `--chrome-*` を `--bg-*` `--fg-*` `--border-*` に、線の太さ
  `--border-thin/thick` を `--stroke-thin/medium/thick` に。
- **文字（アプリ）** — 本文 16 → 14px、補助 14 → 12px。役割名 caption / body / title / heading。
  文字の下限は日本語も 12px。セルは 12px × 表示倍率のまま。
- **密度** — compact / standard（既定）/ comfortable。バー 28/32/40、バー内コントロール 24/28/32、
  フォーム 28/32/40。`--control-h` と `--field-h` の 2 系統。
- **角丸** — lg 10 → 8px、xl 14 → 12px、2xl 16px を追加。
- **重なり順** — アプリの実際の層構造に合わせて `--z-*` を再定義（アプリ層）。
- **大文字の英字ラベルの字間** — 0.04 → 0.08em。
- **暗いテーマの副次テキスト** — すべての背景で 4.5:1 に。
- **バナー** — シート用の `--state-*` ではなく `--*-subtle` を使う（hybrid で警告文が 1.53:1 に
  なっていた不具合の修正）。

### 追加
- 共通基盤：余白 2px・6px・80px・96px、`--stroke-medium`、`--icon-*`、`--bg-hover` `--bg-pressed`、
  `--inverse-*`、`--brand-*`（基準色 5 つ）、`--font-code`、`--text-min`、色 `ink-150` `ink-250` `violet` `teal`。
- アプリ：キャンバスの状態一式（範囲選択・検索・数式の参照・数式・コメント・編集済み・エラー・構文色）、
  テーマに依存しない文書の色 65 色と条件付き書式の既定色、グリッドの寸法、部品（メニュー・タブ・
  数式バー・docked パネル・ツールチップ・進捗・空の状態・グリッド・ソースエディタ）。
- ブランド：流体的な文字サイズ、ページの幅と区切り、44px のボタン、見本の影、`rb-` 部品。
- Design Tokens Format Module 2025.10 形式の JSON（各層の `tokens/`、`$schema` 付き）。
- 生成・監査ツール `tools/build.mjs` と、値の出典 `tools/source/{foundations,app,brand}.mjs`。

### 検証
- コントラスト監査：共通基盤 76/76、アプリ 96/96、ブランド 6/6 合格。
- 手書きの CSS（アプリ 3 ファイル・ブランド 1 ファイル）に色のリテラル 0 件。
- `node design-system/2.0.0/tools/build.mjs --check` で生成物が最新であることを確認。

### 変更なし
- ブランドの色相と段階、ロゴタイプ、アプリアイコン（ファイルは 1.0.0 と同一）。
