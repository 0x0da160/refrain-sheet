DESIGN SYSTEM · v2.0.0 · 2026-09-26

表を主役にする、静かな道具

書式を保持する CSV・スプレッドシートエディタ Refrain Sheet のデザインシステムです。 表計算ソフトに慣れた人が迷わず使える操作感を、独自のモダンな表現で実現するための トークン・部品・グリッド仕様・アクセシビリティ基準をまとめています。 判断の根拠は decisions.md、調査は research.md、v1 からの移行とアプリへの適用計画は migration.md にあります。

v2.0.0 で変わったこと

v1 は汎用 Web アプリの寸法（本文 16px・コントロール 36px）で作られていたため、 表計算の密度に合わず、アプリには色とフォントファミリーしか適用されていませんでした。 v2 は寸法を表計算向けに作り直し、アプリの全画面に適用できる形にしています。

原則

迷ったら上から順に優先します。

  1. 表が主役。周りの枠（バー・パネル）は最小限の高さと色にし、1画面に見えるセルの数を最大にする。装飾は表の外に置かない。
  2. 慣れた操作、独自の表現。矢印キー・範囲選択・右寄せの数値など表計算の約束事は守る。画面の構成・アイコン・色・文言は特定製品をなぞらず、自分たちで設計する（knowledge/decisions/ip-risk-policy.md）。
  3. 状態は常に見え、色だけに頼らない。編集済み・数式・コメント・エラー・選択は、色と形（線・印・太さ）の両方で示す。文字コードや改行コードは常に状態バーに出す。
  4. 密度は選べる。文字は削らない。密度が変えるのは高さと余白だけ。日本語は 13px 未満にしない。
  5. 静かで、即座に応える。セルの移動と選択にアニメーションを付けない。動きは開閉とフィードバックだけ。色は異常時と選択時にだけ強く使う。
  6. データは直角、外側はやわらかく。セル・ヘッダは角 0。シェルの部品は 4〜12px の穏やかな丸み。
  7. オフラインで同じ見た目。Web フォントも外部アセットも使わない。OS 標準フォントだけで成立させる。

色

OKLCH で設計し、sRGB の 16 進で納品します。中間色は暖色の Paper と寒色の Ink の二極で、 テーマはこの 2 極の組み合わせです。v1 の色相はそのまま（ブランド色）で、v2 では暗いテーマの副次テキスト用の ink-150・ink-250 と、数式参照と構文色のための violet・teal を追加しました。

パレット

意味のトークン

トークンは chrome（アプリの枠）と canvas（文書そのもの：グリッド・ソースエディタ）に分かれます。 hybrid テーマは chrome に dark を、canvas に light を使います。canvas の中では chrome-* を使わず、 chrome の中では canvas-* を使いません。この分離が崩れると hybrid で文字が読めなくなります。

緑は 2 つの意味を持ちません。chrome の緑（accent）は「操作・現在地」、 canvas の緑（canvas-selection-border・state-added）は「選択・追加」です。 数式セルの緑の文字は計算結果であることを示し、状態（追加・正常）は示しません。

文書の色（テーマ非依存）

利用者がセルに付けた文字色・塗り色・条件付き書式は データ です。どのテーマでもそのまま描画し、 テーマに合わせて変えません（ダークテーマで黄色い塗りのセルは黄色のまま）。色の選択ダイアログは下の見本を出します。 9 色相 × 7 段階と白・黒で、各段は色相をまたいで明度が揃っています。既定の文字色と塗りは「指定なし」であり、 その場合だけテーマの canvas-text・canvas-bg を使います。

文字

フォント

Web フォントは読み込みません。Windows 11 に標準搭載の BIZ UD ゴシックを基準に、 macOS / iOS はヒラギノ、Android / Linux は Noto にフォールバックします。

トークン用途スタック
--font-uiメニュー・ボタン・ダイアログなど UI 全般"BIZ UDPGothic", "Yu Gothic UI", "Hiragino Sans", "Noto Sans JP", system-ui, sans-serif
--font-dataセル・ヘッダ・数式バー・状態バーの数値"BIZ UDGothic", "MS Gothic", "Hiragino Sans", "Noto Sans CJK JP", "Noto Sans JP", sans-serif
--font-codeソースエディタ・ショートカット表記・コード"BIZ UDGothic", "Consolas", "SFMono-Regular", "Menlo", monospace
  • ウェイトは 400 と 700 だけ。BIZ UD に 500・600 はなく、指定しても 400 か 700 に落ちます。階層はサイズ・色・余白で作ります。
  • --font-data は monospace で終えない。macOS などの汎用 monospace は欧文専用で、日本語のセルが崩れます。
  • 桁揃えは書体で行う。BIZ UD に tnum はありません。BIZ UDGothic は英数が半角固定・かな漢字が全角固定なので、数値列の桁が揃います。スラッシュ付きゼロ（zero）は常時有効です。
  • 円記号。和文フォントは U+005C を ¥ の字形で描きます。表示だけの違いで、保存されるバイトは変わりません。
  • 斜体は日本語の可読性を落とすため、UI では使いません（利用者が書式として付けた斜体は別）。

密度

密度が変えるのは高さと余白だけで、文字サイズとグリッドの寸法は変えません（グリッドは表示倍率で調整します）。 既定は standard です。粗いポインタでは密度の指定にかかわらず 44px を下限にします。 compact でも操作対象は 24px 以上で、WCAG 2.2 の 2.5.8（最小ターゲット 24×24px）を満たします。

  • 数値・日付は右揃え、文字列は左揃え、真偽値とエラーは中央。
  • 交互の縞はオフが既定。利用者の塗り色と競合するためです。
  • 固定した行・列の境界は 2px の canvas-frozen-divider。
  • セル内のエディタはセルと同じ位置・同じ行送りに文字を置き、2px の枠と影で「浮いている」ことを示します。
  • ソースエディタ（JSON・YAML・Markdown・テキスト）もキャンバス側です。構文色は syntax-* で、色がなくても構造が読めることを前提にします。

操作と文言

動き

  • グリッドの移動・選択・スクロールは 0ms。表計算で最も頻繁な操作に遅れを入れません。
  • メニュー・ポップオーバー・パネルの開閉は --duration-base（200ms）以内。閉じるときは開くときより速く。
  • アニメーションするのは opacity と transform だけ（レイアウトを動かさない）。
  • コピー元の点滅は、動きを減らす設定では止めます。

キーボードとフォーカス

  • 全操作がキーボードで行えます。フォーカスリングは消しません。
  • グリッドは 1 つのフォーカス対象で、中の移動は矢印キーで行います（roving）。Tab は次の領域へ移ります。
  • 日本語 IME の変換中は、Enter・Esc・矢印キーを確定やセル移動として扱いません。
  • ブラウザが使うキー（タブ・ウィンドウ操作・再読み込み・拡大・印刷・開発者ツール）は奪いません。

文言

  • ボタンは動作を表す語で書き、取り消せない操作では対象も書きます：「保存」「削除」「3 行を削除」。「OK」「はい」は使いません。
  • 確認では対象と結果を名指しします：「『Sheet1』の 12〜14 行目を削除します」。
  • エラーは「何が起きたか」「なぜか」「どうすればよいか」の順に、利用者の言葉で書きます。コードやスタックトレースは詳細に畳みます。
  • ファイルを変えるかどうかを常に明示します（「ファイルは変更されません」「保存すると改行コードが LF になります」）。
  • すべての文言は src/locales/en.json と ja.json にあります。日本語のラベル・ボタン・メニューは体言止め（「保存」「ファイル名」）、説明文とメッセージは敬体（です・ます）にします。

運用の決まり

  • 色のリテラルを書かない。トークンと同じ値の生の色は、テーマに追随できない形で書かれたそのトークンです。base.css・components.css・grid.css に色の値や色関数があるとビルドが失敗します。
  • バージョン。トークンの削除・改名・既定値の変更はメジャー。追加はマイナー。微調整と文書の修正はパッチ。版ごとにディレクトリを分けます。
  • 昇格と刈り込み。同じ見た目が 2〜3 か所で独立に現れたら、名前を付けてトークンか共通クラスにします。使われなくなった部品は削ります。
  • 規範は根拠であって法ではない。画面で確かめられる制約（フォントにないウェイト、OS の描画、コントラスト）が一般則と衝突したら、制約を優先し、その理由を decisions.md に書きます。
